## 视觉调整

- 顶部名称配爪印，VIP 继续是无购买逻辑的不可用占位。
- 顶部组合图完整放进奶油粉、淡紫、雾霾蓝渐变卡片；标题与辅助文案保持，移除人为换行，让文字自然排版。
- 组合图以宽度和 1419:515 比例计算高度；独立图也保留各自比例，统一 ContentScale.Fit，不拉伸、不用 Crop，不新增切掉猫狗耳尾的裁剪。
- 常规字体使用横向宠物卡片：独立插画在固定比例的图片区域内居中，右侧是名称与选中状态，去除重复辅助描述。
- 字体倍率达到 1.3 时宠物和场景卡片改为上下居中布局；品牌与 VIP 分行，录音按钮改为图标在上、文字在下。保留完整字号和文案，避免窄屏逐字竖排。
- 场景保持两列三行，以图标与文字并排压缩常规高度；所有选择项保留至少 48dp 点击区域、RadioButton 语义、整卡点击、水波纹和背景/边框颜色过渡。
- 大圆角白卡片、轻阴影、深蓝文字；保留粉蓝录音渐变、固定底栏与原安全区处理。页面整体间距由 16dp 改为 10dp，仍可完整滚动。

## 前后高度对比

同一 Pixel 3 / Android 10 / 1080×2160 / density 440，逻辑宽度约 392.7dp，常规字体，首页初始未滚动状态。顶部位置相对 Compose 根节点，包含顶部安全区域；比较的是整个区域，不仅是图片或选项本身。

| 区域 | 升级前 | 升级后 | 减少 |
| --- | ---: | ---: | ---: |
| 顶部插画卡片高度 | 246.5dp | 192.4dp | 54.2dp / 22.0% |
| 宠物选择区域高度 | 262.9dp | 113.1dp | 149.8dp / 57.0% |
| 场景选择区域高度 | 412.0dp | 212.4dp | 199.6dp / 48.5% |
| 录音按钮高度 | 74.5dp | 63.6dp | 10.9dp |
| 录音按钮顶部位置 | 1065.8dp | 632.7dp | 上移 433.1dp / 40.6% |

原始测量：[before/layout.txt](a1.1.1/before/layout.txt)、[after-threebutton/layout.txt](a1.1.1/after-threebutton/layout.txt)。常规 Pixel 3 三键导航初始页面可见按钮上缘，轻滑即可看到完整按钮；未宣称所有设备均可一屏完整展示。大字体优先可读性，页面高度会增加。
