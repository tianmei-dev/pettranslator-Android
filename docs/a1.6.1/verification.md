# A1.6.1 首页一屏适配

本次生产代码仅修改 HomeScreen.kt，设备测试增加未滚动前的主要内容可见性检查。

## 原因与调整

原页面主视觉、卡片 padding 和模块间距叠加，内容高度超过 Scaffold 分配给首页的空间。导航 Insets 已由 Scaffold padding 和 consumeWindowInsets 处理，未发现重复计入，不修改导航容器。

保留原插画和艺术字体；插画高度按 Scaffold 剩余可用高度调整为 82–110dp，使用 Fit 保持比例。模块间距 10→6dp，底部留白 18→6dp，模块内边距 10→8dp，卡片竖向内边距 8→5dp。场景图标 46→34dp，三列两行保持固定；场景文字可换行。补全两个右对齐副标题，大字体时给主标题与副标题分别分配宽度并允许换行。保留滚动作为空间不足与无障碍兜底。

## 真机尺寸对比

Pixel 3，Android 10，1080×2160，440dpi，字体倍率 1.0。下列约数由前后完整截图按设备密度换算，包含模块容器。

| 区块 | 修改前 | 修改后 |
| --- | --- | --- |
| 顶部主视觉 | 243dp | 212dp |
| 宠物选择模块 | 114dp | 99dp |
| 场景选择模块 | 238dp | 180dp |
| 录音按钮 | 原代码约62dp，首屏不可见 | 约52dp，首屏完整可见 |

home-before.png 为修改前真机截图；home-after.png 为最终 APK 的完整首页截图。按钮、娱乐提示、六场景、两个副标题及底部 Tab 均无需滚动可见。首页无“把我的话说给它听”入口。

当前只连接 Pixel 3，三星主要验收设备尚未验证；320/360/412dp 及大字体尚未逐一进行设备截图验收。较矮屏压缩插画区域，内容超出时滚动；不强制修改系统字体。
