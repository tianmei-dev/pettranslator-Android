## 状态机

| 状态 | 含义和出口 |
| --- | --- |
| READY | 无采集。点击开始后通过系统权限并确认前台，进入 STARTING。拒绝权限仍留在此状态并解释原因。 |
| STARTING | 后台初始化 AudioRecord；首批真实 PCM 到达才进入 RECORDING。禁止重复开始，可取消。 |
| RECORDING | 真实计时、进度、振幅。停止进入 STOPPING；采样上限或单调时钟 10 秒上限自动结束。 |
| STOPPING | 等待原任务释放；手动停止交付完成，取消/中断则回 READY。禁止新实例并行启动。 |
| COMPLETED | 文件已关闭、麦克风已释放。仅显示 AI 下一阶段接入提示，可重录或返回。 |
| ERROR | 初始化、占用、读取、存储或权限异常；不交付半成品，可重试或返回。 |

停止命令使用原子状态，整个会话只有一个采集协程。代次标记丢弃取消后的迟到采样/结果；旧任务释放完之前不允许重启。协程取消异常直接传播，不能当作普通录音错误包装。手动和自动停止不会各自产生一份完成结果。

## 音频数据与 A1.2.2 交接

`RecordedAudio` 包含：

| 字段 | 含义 |
| --- | --- |
| filePath | 应用私有 cacheDir/pet_recordings 下临时文件绝对路径 |
| sampleRate | 实际 AudioRecord 采样率，当前要求并校验为 16000 |
| sampleCount | 实际已写入的单声道采样数，最大 160000 |
| durationMs | sampleCount × 1000 / sampleRate |
| format | PCM_S16LE：有符号 16 位小端、无 WAV 头 |
| channels | 1，Mono |
| rms / peak | 归一化基础音量统计，不代表内容识别或质量结论 |

文件最大 320000 字节。后台 IO 使用短整型读取，逐样本写入小端 PCM。单调时钟 elapsedRealtime 限制墙钟录音不超过 10 秒，采样数限制防止输出超长；不会通过 UI 动画帧计时或补静音凑时长。

交接入口：`RecordingViewModel.completedInput()` 只在 COMPLETED 返回 `RecordingInput(audio, pet, scene)`。A1.2.2 可以按唯一 filePath 消费一次，在后台读取并分析；当前没有注册分析器或自动执行 AI。文件仍归录音页所有，必须在重录、返回或页面释放前消费。后续若要跨目的地持有文件，应明确转移所有权，不可把路径保存成历史记录。

必须检查实际音频内容；即使有时长、有样本或 RMS，也不证明是有效猫狗声音。系统可能回收 cache，后续消费者还需要处理文件不存在。原始音频从未导出到本交付目录。

## 权限处理

只声明 RECORD_AUDIO。首页和进入录音页都不会提前弹权限，只有点击“开始录音”才使用 Activity Result API 请求。首次拒绝显示简短原因，用户可再次尝试；系统不再显示弹窗时按回调及 shouldShowRequestPermissionRationale 提供应用设置入口。不会用永久“请求过一次”标记错误拦截一次性权限过期后的合法重新申请。

重复点击不会并行请求权限。授权返回时等页面 RESUMED 且窗口获焦再启动；从设置返回只刷新授权状态，需用户再点击开始。引擎采集中复查权限，SecurityException 安全转为失败并释放；系统撤权若直接终止进程，则下次启动清理孤儿文件并回到非录音状态。

参考 [Android 运行时权限指南](https://developer.android.com/training/permissions/requesting)。

## 生命周期、异常及释放

- 只有录音目的地 RESUMED 且窗口获焦才允许启动；ON_PAUSE、失焦、返回、页面释放和 ViewModel 清理都会取消活动录音。
- Activity 重建不恢复麦克风会话；当前临时结果也不作为可恢复业务状态保存。宠物和场景通过导航参数恢复，首页选择维持原状态机制。
- AudioRecord 仅在 IO 线程构造/启动/读取。read 使用非阻塞模式并短暂挂起，正常无数据超过 1.5 秒报错，避免忙等和静默假录音。
- 初始化/启动、读取错误、被其他客户端或通话占用、较新系统的 client-silenced 都有明确错误出口。录音中断不会交付成功音频。
- 所有出口经 finally stop/release，释放异常也不会跳过文件清理和运行标记复位。取消会删除当前文件；完成文件在重录/退出时删除。
- 进程被杀无法再执行 finally，麦克风由系统回收；未完成私有缓存可能短暂遗留，下一次 Application.onCreate 清理本模块 capture_*.pcm。进程不再启动时由系统缓存回收机制管理，未引入后台清理服务。
- 不上传、不写公共存储、不增加历史、分享或后台服务。

音频输入共享行为参考 [Android 音频输入共享规则](https://developer.android.com/media/platform/sharing-audio-input)；采集接口参考 [AudioRecord 官方 API](https://developer.android.com/reference/android/media/AudioRecord)。
