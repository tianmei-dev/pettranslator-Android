# A1.1 交付记录

日期：2026-10-23。工作目录：`D:/pettranslator`。原目录为空，本次文件均为新增；未进入 A1.2。

## 实现范围

- Kotlin / Jetpack Compose / Material 3 / MVVM，Gradle Kotlin DSL。
- minSdk 26，compileSdk / targetSdk 36，Java 字节码目标 17。
- 奶油粉与雾霾蓝浅色主题、深蓝文字、渐变与圆角卡片。
- 顶部名称、禁用语义 VIP 占位、独立绘制猫狗插画。
- 猫狗单选，首次默认猫咪，DataStore 保存最近选择；异步恢复期间禁用相关交互。
- 六场景单选，两列三行，默认不确定，SavedStateHandle 保存场景状态。
- 录音按钮、人声入口及轻提示；趣味声明。
- Compose Navigation 三个 Tab、状态恢复、单实例导航、占位页返回首页。
- 滚动内容、固定底栏、安全区域、单选无障碍语义、点击水波纹与选择背景动画。
- FeatureAccessManager 默认放行及携带宠物/场景的 RecordingEntry 接入点。

没有登录、VIP 查询、支付、免费次数、录音权限或录音逻辑、YAMNet、解读规则、结果页、服务端实现。

## 技术结构

详见根目录 README。UI -> HomeViewModel -> PetPreferences 接口 -> DataStore，Compose 仅展示状态与派发交互。手动注入依赖，避免为本次范围增加框架或空类。HomeViewModel 位于 Activity 作用域，Tab 切换不重建首页业务状态。
