## 布局与适配

顶部取消独立圆角渐变卡片，房间图片位于底层，轻微粉白渐变遮罩提高文字可读性；品牌与 VIP、双色标题、辅助文案、猫狗组合图分别为真实 Compose 层。背景使用 Crop，角色使用 Fit 和原始比例。顶部高度由文字、字号和图片比例共同决定，没有固定大高度。

宠物仍为横向两列，常规字号采用紧凑图文布局，大字体改上下排列，保留粉色勾选、RadioButton 语义、整卡点击、水波纹和背景/描边过渡。

场景常规按门窗/吃饭/玩耍、独处/被抱起/不确定排列，图上字下，统一 46dp 图像槽、Fit 保留素材比例。场景可用内容宽度不足 290dp（对应页面约 350dp 以下）或字体倍率达到 1.3 时回退两列；320dp 为两列，360dp/411dp 常规字体为三列。卡片最小点击区域 48dp，不限定文字行数，文字填满可用宽度并自然换行，卡片按内容增高。

录音入口保持原事件与参数，粉蓝渐变胶囊、麦克风、少量星光和轻阴影；大字体图标文字上下排列。人声入口在其下，主文案为“把我的话说给它听”，辅助文案“人声变宠物语”，整卡可点击。趣味声明与固定底栏、安全区域处理保留，内容可完整滚动访问。

## 与原设计稿的主要差异及人工确认项

1. 房间素材为 1536:433 横向全景，手机竖向顶部 Crop 保留主要窗景，但左右花丛和窗帘无法同时完整展示；大字体时裁切区域还会随内容高度变化。
2. 正式组合图为猫左狗右，原设计稿为狗左猫右。沿用开发者提供的角色构图，没有镜像或修改形象。
3. 标题使用系统字体与双色强调，未复制原稿手写字形。顶部为滚动的分层区域，系统状态栏与导航栏均使用真实 Android 样式。
4. 角色图和房间图各自包含靠垫等装饰，叠放并非设计稿中一体绘制的原始构图。需开发者确认最终视觉；源素材残片/毛边如需消除，建议设计侧提供精修透明图。
5. 窄屏及大字体两列回退、自然换行是为可读性保留的差异；不强制所有内容一屏展示。
6. 本轮已验证 Android 15 真机的两种导航，Pixel 3 / API 26 / API 36 及其他厂商机型仍需后续设备矩阵复核。

没有录音、YAMNet、翻译规则、结果页、登录、VIP 购买、支付或服务端实现。
